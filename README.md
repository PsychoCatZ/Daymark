# Daymark

Daymark — законченный демонстрационный интернет‑сервис для планирования дня и фокус‑сессий. Проект создан для портфолио веб‑разработчика и не представляет реальную компанию или коммерческий продукт.

## Что реализовано

- план задач по дням с представлениями «Сегодня», «На неделе» и «Готово»;
- добавление и редактирование задач с валидацией формы;
- завершение и удаление задач с подтверждением;
- фильтрация по рабочим и личным задачам;
- поиск по названию и проекту;
- 25‑минутный фокус‑таймер с паузой и сбросом;
- отметка текущего уровня энергии;
- сохранение задач, таймера и самочувствия в `localStorage`;
- WebMCP‑действия для чтения, добавления и завершения задач совместимым браузерным агентом;
- адаптивные компоновки для desktop, tablet и mobile;
- клавиатурная навигация, семантическая разметка, подписи полей, skip‑link и заметные focus‑состояния;
- обработка пустых результатов, неверного ввода и неизвестных URL.

## Стек

- HTML5;
- CSS3 без UI‑фреймворка;
- современный JavaScript без runtime‑зависимостей;
- Node.js для локального статического сервера и smoke‑тестов;
- Git.

Проект намеренно не использует сборщик и внешние зависимости: его можно запустить сразу после клонирования, если установлен Node.js 18 или новее.

## Локальный запуск

```bash
git clone <URL-репозитория>
cd daymark-planner
npm start
```

После запуска откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

Устанавливать npm‑пакеты не нужно.

## Проверка проекта

```bash
npm test
```

Команда проверяет структуру документа, наличие адаптивных и accessibility‑стилей, синтаксис JavaScript, запуск локального сервера, отдачу HTML/CSS/JS и корректный ответ 404.

## Структура

```text
dist/
  index.html       интерфейс и семантическая структура
  styles.css       визуальная система и адаптивы
  app.js           данные, состояние и взаимодействия
scripts/
  server.mjs       локальный сервер без зависимостей
  smoke-test.mjs   автоматическая проверка чистого запуска
```

## Основные особенности

Визуальная идея Daymark — «цифровая канцелярия»: строгая модульная сетка, насыщенный синий, солнечный жёлтый и крупная типографика. На desktop навигация закреплена сбоку, на tablet становится компактной, а на mobile превращается в нижнюю панель. Основная рабочая зона доступна сразу, без рекламного экрана перед сервисом.

Все демонстрационные данные вымышлены и хранятся только в браузере пользователя.
